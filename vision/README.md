# Vision Resources

This repository contains the ESP32-S3-side prediction message handler, but no camera firmware, image preprocessing, model, model conversion files, labels, training notebook, data set or evaluation results. The main controller waits for three prediction strings and votes between GREEN and WHITE.

Do not claim model training, accuracy, inference performance or camera-side implementation based on this interface alone. Add model artifacts only after checking provenance, size, license and redistribution rights. See [model unknowns](../docs/ESP32CAM_MODEL_IMPLEMENTATION.md) and [pipeline](../docs/ESP32CAM_INFERENCE_PIPELINE.md).
